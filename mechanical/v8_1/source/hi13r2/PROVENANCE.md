# HI13R2 官方资料与装配基准

获取日期：2026-09-22。型号选用 **HI13R2-USB-000**。以下来自厂家发布的 HI13 共用外壳资料；R2 内部配置为加速度计和陀螺仪，无磁力计、无气压计。

第17、18、19页已分别渲染为 `datasheet-17.png`、`datasheet-18.png`、`datasheet-19.png`，用于机械尺寸、安装要求和坐标轴的目视核对。文本抽取另存 `hi13_datasheet_cn.txt`。

## 机械与原点

第17页图9给出壳体24×24×12 mm，接口突出2 mm，总包络26×24×12 mm。两处对角贯穿安装孔为 **Ø2.6 mm**，X/Y方向中心距均为 **20.2 mm**；安装螺钉采用 M2.5。接口端面的 **2×M2、15 mm间距** 是连接器锁紧板螺孔，不能与竖直安装孔混用。

图9以红点标注 IMU 位置，D4=12 mm、E3=12 mm、A3=6 mm，分别从壳体两边与安装底面定位。三个参数表格范围均为名义值±0.2 mm。该点是厂家公布的模块名义参考点，并非对每台设备芯片实际敏感中心的独立标定结果。

本装配将该名义点放在机器人 **(X,Y,Z)=(0,0,85) mm**，安装底面 **Z=79 mm**，上表面 **Z=91 mm**；俯视参考点落在机器人坐标原点。安装孔世界坐标为 **(10.1,−10.1)**、**(−10.1,10.1)**。最大头部高度会达到Z91.9：Ø4.5×2.5 mm的M2.5圆柱头落在Z89.4的螺钉支承面上。

建议与3 mm厚刚性金属桥搭配：桥Z76..79、Ø2.7通孔、M2.5×16螺钉和桥下约2 mm厚螺母，螺钉末端Z73.4。紧固件的真实头部、螺母和螺纹长度仍应按所购物料校核。不采用未标定的软垫悬置。

## STEP 到机器人坐标变换

原 STEP 含两个有效实体，主要为外壳和盖板；未凭空增加内部 PCB、芯片或USB插头。STEP 的壳顶指向原始 **−Z**，接口朝 **+Y**；这一点由前部螺孔翻转后距底4.95 mm吻合图纸A2=5，以及顶部安装槽支承面距底10.4 mm吻合A1=10.4交叉核对。

原始图示 IMU 点：`(-40.00155697274189, 1.47316173360338, 0)`。

安装变换（单位mm）：

```text
X_robot = -(Y_STEP - 1.47316173360338)
Y_robot = -(X_STEP + 40.00155697274189)
Z_robot = 85 - Z_STEP
```

这是行列式为+1的刚性旋转和平移，没有镜像。接口朝机器人 **−X**，便于将线束引向后部。

第19页图10定义默认传感器 **RFU** 轴：Y朝接口、Z朝上。安装后，传感器Xs对应CAD +Y，Ys对应CAD −X，Zs对应CAD +Z。将原始加速度、角速度转换到CAD数值坐标，应采用：

```text
v_CAD = [[0, -1, 0],
         [1,  0, 0],
         [0,  0, 1]] * v_sensor
```

这里明确使用CAD数值轴，不依赖旧模型左右侧命名。姿态四元数/欧拉角需按固件的参考坐标、输出约定做完整外参转换，不能直接置换欧拉角。当前没有修改控制器或设备配置。

## 质量和边界

- 重量预算使用 **11 g**，对应厂商“小于11 g”的保守上界，不按空心外壳体积代替整机IMU质量。
- 产品典型功耗300 mW，USB供电范围4.5..5.5 V。
- `cable_clearance()` 只提供20×12×9 mm设计预留区，**不是**厂家USB线插头模型；实际选线后应复核插头、弯曲半径和应力释放。
- 安装应平整、刚性固定，远离集中热源，避免线束持续拉扯；跳跃与振动工况需在整机上实测验证。
- `model_validation.json` 检查真实STEP的有效性、2个实体、26×24×12 mm包络、底面高度、原点转换，以及两个孔轴Ø2.5探针无实体重叠/螺钉支承环存在材料。

可复现代码：`tools/cad_v7_imu.py`；装配接口参数：`interfaces.json`。安装BRep缓存 `hi13r2_placed_z79.brep` 来自原始实体刚性移动，原始STEP始终保留。
