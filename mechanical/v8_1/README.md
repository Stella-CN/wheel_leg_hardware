# V8.1 单台样机细化版

在V8基础上细化紧固件、少量接口和安装顺序。保留5寸前脸、小R5长方体机壳、腿部杆长与嵌套关系、电机及轮组坐标；V8文件未覆盖。主承力路径为金属轮辋/下臂/关节/OB与电机法兰/髋座/金属机架，打印壳体不参与这条承力路径。

## 总装先后关系

1. 预装左右整腿；在裸髋座阶段预放四颗M4×12，临时防掉。
2. 预装金属机架，保持电器仓为空，保留机内工具空间。电池和窄托在机外预装并穿好两条束带。
3. 整腿在180 mm髋轮距靠入机架，垫片与螺母从内侧放入；后上螺钉在110 mm姿态锁紧，其余三颗在165 mm姿态锁紧。两腿均需工装支撑，移出工具后才能调姿态。
4. 从上方放入整套电池/托盘模块，锁紧4颗M3×8，再装已预装的Jetson托盘及IMU桥。
5. 装前壳，再安装已预装的屏幕/相机前脸；布线检查后装后盖和肩罩。

新窄托消除了旧58mm宽托盘的后装干涉，整托+电池+底部单层束带的100mm连续竖直扫掠已检查。更换电池模块需先腾出上方主机托盘通道。工具及坐标限制以模块装配文件为准。

## 制造时的重点

- 承力金属不能根据外观直接替换PETG；带台阶、轴承座及凸台的铝件不能把板材毛坯直接视为普通钣金成品。
- 金属加工以STEP和书面公差共同为依据。CAD中许多螺纹用底孔表示，完整牙深、孔底余量、去毛刺和表面处理遮蔽必须落实到加工工艺；STL不用于精密配合验收。
- A/B/C使用同一种6×19×6轴承。先测轴承和加工孔，铜套肩按实测叉距选配，避免用端部M2把轴承预紧或叉耳拉弯。限位销只用于装配限位，不能承担带电撞停。
- 指定沉头件为DIN7991目录尺寸；M3头Ø6/k1.7，M4头Ø8/k2.3，不能无条件代换大头ISO10642。HI13R2的M2.5螺钉须核对光头Ø≤4.5。
- PETG打印孔、捕获螺母槽和壳体舌槽先做同方向试片。保持220×220×250 mm打印包络，壳体使用可拆支撑；不要整体缩放补孔。
- D435后座按实物深度选25.05或26.05 mm版本，后一版本在`alternates/`，为替换件。5寸屏规格书未给完整安装孔及玻璃边界，使用外框托夹，首件确认四角只压金属外框。
- 新电池安装范围X±42.8、Y±22.25、Z−43.8～17.8mm；每侧0.5mm装配间隙，采用两条10×300mm束带，底部单层厚≤1mm。DC侧朝上，设计预留11mm插头/走线高度；真实孔位和弯头尚未给尺寸，不能把该检查区当作已验证的插头。详见[BATTERY.md](BATTERY.md)。

## 验证范围

- FreeCAD原生主腿杆、髋座、膝杯、轮辋、电机和轮胎共30个对象的体积、表面积、包络与运动表达式对比V8一致。
- 100～215 mm、每5 mm一档，共24个腿长姿态，Beta=0°，受检刚体相对运动对未发现超出0.05 mm³阈值的实体相交。不是连续全工况证明。
- 276个外部连接硬件对象在100/180/215 mm姿态的原生摆位检查通过。
- 整腿携预装M4的10个轴向接合位置、指定外内工具通道、新电池模块的连续保守落入包络均完成检查。手掌、手柄、线束和连接器实物不在这些几何包络内。
- 全部独立PETG STL封闭、法线一致，无被检测到的非流形或自相交；摆放尺寸满足打印机限制。制造共用件以双向布尔差检查，而非只凭左右外观判断。
- 工作簿数量与CAD实例逐项核对；Excel公式由artifact-tool重算并测试备件比例，未在原生Excel应用引擎中测试。
