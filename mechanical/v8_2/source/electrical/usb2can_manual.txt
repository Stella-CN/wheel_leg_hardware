二、产品介绍
  本产品是一款高性能 USB 转双通道 CAN FD 通信模块，专为工业自动化、汽车电子、智能交通及嵌入式
开发等高可靠性通信场景设计。模块支持两路独立 CAN FD 通道，兼容传统 CAN 2.0B 协议，最高数据速率可
达 5 Mbps，显著提升总线通信效率。
  集成 USB High-Speed（USB HS）接口，配合优化驱动与硬件缓冲机制，实现百万帧连续收发不丢包的
稳定性能，满足严苛实时通信需求。同时，模块还支持 USB 转 UART 功能，一机多用，灵活适配串口调试、
设备升级等多种应用场景。
  即插即用，支持 Windows/Linux/macOS 主流操作系统，并提供丰富的 API 与 SDK，便于快速集成与二
次开发。是工程师进行 CAN FD 总线测试、数据分析、网关开发的理想工具。

六、模块使用说明

( 一 ) 连接上位机

 此模块只支持 2.1.5.x 版本及以上上位机，使用前请注意上位机版本。
 设备连接流程如下：
 1. 插入设备：将设备连接至 PC，打开上位机软件；
 2. 刷新设备：如软件匹配到可用设备会自动选择串口号；
 3. 打开串口：点击序号②的【打开串口】按钮完成连接端口号；
 4. 状态确认：成功连接后，设备指示灯由蓝灯闪烁变为绿灯闪烁。

( 二 ) 查看设备版本

  在连接上位机的情况下按下 F9 快捷键呼出模块固件升级窗口，点击读取版本即可读取当前模块固件版本。




( 三 ) USB2UART 功能

  本模块提供 USB2UART 功能，通过 USB 发送和接收的数据都直接转发到 UART 接口，无其他协议处理，
支持常用的串口助手。当双方设备处于相同波特率时，使用上位机的串口助手查看数据可正常接收。如果双方
波特率不同，则无法显示出错误的内容。

( 四 ) 配置 CAN 通道波特率

  1.CAN2.0 模式
  ① 在主界面按下 F2 快捷键打开设备配置窗口；
  ② 切换工作模式：将设备通信类型设置为 CAN2.0；
  ③ 配置波特率：选择 CAN 波特率（支持 1Mbps、500kbps、250kbps、200kbps、125kbps、100kbps
等常用波特率）；
  ④ 应用配置：点击更新配置按钮。

 2.CANFD 模式
 ① 在主界面按下 F2 快捷键打开设备配置窗口；
 ② 切换工作模式：将设备工作模式设置为 FDCAN；
 ③ 配置波特率：
 ・ 仲裁域波特率：最大支持 1Mbps（可 1Mbps/500kbps/250kbps/200kbps/125kbps/100kbps 等）；
 ・ 数据域波特率：最大支持 5Mbps（可选 5Mbps/4Mbps/2.5Mbps/2Mbps/1Mbps 等）；
 ④ 应用配置：点击更新配置按钮。

 ( 三 ) 配置通道波特率以及模式

  在配置通道模式以及波特率之前需确保当前通道处于 down 模式，配置前可以输入下列指令来配置成
down 模式。


   sudo ip link set can0 down
   sudo ip link set can1 down


  这里以配置仲裁段 1M 波特率 ( 采样点 75%) 以及数据段 5M 波特率（采样点为 87.5%）为例子，输入下
面指令。


   sudo ip link set can0 type can \
       bitrate 1000000 \
       dbitrate 5000000 \
       sample-point 0.75 \
       dsample-point 0.875 \
       fd on


   sudo ip link set can1 type can \
       bitrate 1000000 \
       dbitrate 5000000 \
       sample-point 0.75 \
       dsample-point 0.875 \
       fd on


  配置完后可以输入下面的指令来查看配置是否生效。


   sudo ip -d link show can0
   sudo ip -d link show can1

( 四 ) 开启通道


   sudo ip link set can0 up
   sudo ip link set can1 up


  输入完上面指令后可以观察到模块的两个通道指示灯亮起。
