# V8.2 电气与后部接口集成

在V8.1基础上加入顶部自锁电源开关、后部充电接口安装板、双路USB2CAN、用户分配PCB、24→19 V转换器及四口USB扩展坞。保留5寸前屏、上方D435、小圆角机壳和腿部机构；Jetson、IMU、电池与两腿位置沿用基线。

新增服务架、扩展坞压托和充电安装片可PETG打印；修改的前主壳、后检修壳及电子盘均保持原材料分类。金属承力件和腿部运动结构不因本次电气集成改为打印件。

开关、转换器和扩展坞使用用户尺寸图建立外形；两块板采用提供的真实STEP。形状模型不包含可验证的PCB导电网络，电源分配的线序和额定值仍需电气资料/实测。

## 接线与维修

电池共口一分二：充电支路在总开关前，负载支路经过顶部开关后分别供给电机分配及24→19 V模块。电机动力电气并联；每条腿的CAN顺接髋、膝、轮，左右为两路独立总线。USB2CAN的供电和上位机数据来自USB，不从CAN口输入电池电压。

Jetson四个Type-A分别接D435、USB2CAN、屏幕USB和背部扩展坞；Type-C Host接HI13R2，DisplayPort经DP→HDMI接屏幕。扩展坞原150 mm线增加一根250 mm USB3 A公母延长线，绕机体正Y侧高位布置；背部四口全部保留给外接设备。后盖可连扩展坞作为整体拆下，充电口用独立小板便于后续换型。

安装遵循“两腿与空机架→电池→电子盘/M07→IMU→带开关前壳→前脸→带扩展坞后盖→肩罩”。支架底部螺母、板卡和转换器都先在机外完成，避免在满装电器仓内散装小零件。新增竖板改变维修包络，旧版Jetson后抽路径不能直接移用。

## 证据范围与待完成项

- `electrical_build.json`记录改动对象、新增硬件和基线哈希；[最终电气结构检查](electrical_final_validation.json)记录实体相交及基线对象保留情况；[路由空间检查](routing_validation.json)记录预留走廊及`all_clear`结果。使用报告时核对版本/哈希，`all_clear`只代表所列占位几何的检查，不代表真实线缆已验证。
- 基线腿部装配、公差、已选紧固件和历史检查保存在`baseline_v81/`。本版新件不能只引用旧检查通过。
- 走线对象只表示预留空间，没有证明实物插头可插入、弯曲半径合格或腿部动态线束寿命。接头尺寸、护线件和线束下料需试装落实。
- 后部DC母座的安装螺纹/孔径未给；现有Ø3是导孔。顶部开关DC分断能力/LED电压、转换器输入范围与功率、用户板的网络/载流尚未确认。
- E626S持续6 A；满充25.2 V不可直连Jetson。J4310 V1.1手册最低工作电压表述不一致，本版按更严格20 V审查，不能把电池18 V截止视为可用运行下限。现有供电未获跳跃能力验证。

本版用于模块装配、加工准备及样机试装；原始V8.1未覆盖。完整验证结果、数量和质量以本版相应报告为准，外购设备的未测质量保持工程预算标记。
