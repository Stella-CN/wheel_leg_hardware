# V5 紧凑髋膝连接法兰

两件结构保留：P1 连接髋转子，P2 连接膝后壳。总轴向跨度由 V4 的 21.8 降至 **14.9 mm**，缩短 6.9 mm；最大直径仍为 57 mm。每腿两件 CNC，全机四件。左右杯件不能直接翻面互换，使用各自 STEP。

文件：[截面及孔系 SVG](cnc/coupling_section.svg)、[PNG](cnc/coupling_section.png)、[局部 FreeCAD 装配](coupling_local_review.FCStd)、[几何报告](coupling_review.json)、[销及紧固件规格](coupling_fasteners.json)。

| 特征 | 最终尺寸／层面，mm |
|---|---|
| P1 前颈 | D39，Y72.2～75.5；定位口 D35.05×深0.8，贴合髋转子面Y73 |
| P1 套芯 | D43，Y75.5～82.5，套合长度7 |
| P2 杯件 | 外D57／套孔D43.05，Y75.5～87.1；底盘厚4.6 |
| 转子螺钉 | 6×ISO4762 M3×8，PCD27，相位0°；夹5、名义入牙3，头Y78～81 |
| 原厂定位销 | 3×D4×L9，PCD24.30，相位90°/210°/330°；入电机3、入法兰6，销底余肉3.5 |
| 膝后壳螺钉 | 4×NBK SLH-M3-6-SD，PCD38，相位45°；头Y82.6～84.6，铝承压2.5，名义入牙3.5 |
| 径向锁紧螺钉 | 4×NBK SLH-M3-8-SD，Y79.5，相位15°/105°/195°/285°；承压R26.3，头顶R28.3，名义入牙3.2 |
| 径向螺纹底孔 | D2.5圆柱深4.5，另留118°钻尖；加工完整M3×0.5螺纹至少3.5深 |

NBK 小头低头螺钉头径 D4.5±0.1、头高2、内六角2、8.8级。膝后壳 D4.8 沉孔完全落在 D43.05 套孔内，取消了 V4 杯壁上的四条轴向工具缺口。头径上限 D4.6 的包络也已检查。规格来自 [NBK 官方 SLH-SD 数据](https://www.nbk1560.com/images/en-US/product/lowsmallheadscrew/SLH-SD/SLH-SD_1.pdf)，已保存于本目录 `source/`。

小头会提高铝座承压，厂家列出的 1.4 N·m 仅是螺钉本体上限，不能直接作为此连接的锁紧扭矩。径向名义头下承压面积为 6.825 mm²，连接扭矩需按实际材料、预紧和负载确定。不得直接替换为普通高头螺钉。

装配顺序：先把带定位销的 P1 固定在髋转子；从杯口把 P2 固定到膝后壳；对孔套入7；最后均匀锁紧四颗径向螺钉。拆卸从径向螺钉开始。定位销法兰端固定、电机端可拆的配合需用实物孔确认，不将三根销默认设为电机端过盈。

几何检查通过：两个 CNC 件、17个硬件和双原厂电机无超过0.001 mm³的相交；14条真实六角工具路径畅通；沿轴线0～8 mm的六个套装位置均无相交。与 V5 实际髋板及其硬件无相交，四条侧向工具路径最小距板0.5。最小实测孔壁为转子沉孔至径向底孔1.652、定位销孔至转子沉孔1.866；杯口前唇1.6。图中的刀具至杯孔0.125径向间隙不是结构残留薄壁。

新电机层面：膝后壳Y87.1，整只电机平移Y132.6，前定子面Y132.1，转子面Y133.1。`tools/cad_v5_coupling.py` 的 `configure()` 返回这些基准且不修改全局参数；`designs(P)`、`hardware(P)` 供整机构建调用；`build(P, output_directory)` 生成局部审查包。完整销已在局部真实电机孔中检查，整机硬件略去进入刚体STEP转子的3 mm，以避免运动时静态转子孔引起假碰撞。

本版为制造审查原型；配合公差、实物装配、铝螺纹、预紧和疲劳承载仍需确认。
