# V8：5寸屏、小圆角箱式机身

本版按新 GK-HD V3 规格书选择 **5寸屏**。前脸是一块完整可拆面板，屏幕在下、D435在上；机身采用平直六面与 R5 小圆角，取消斜切多折面。Jetson、相机及 HI13R2 全部安装于同一个中空机壳内。

**腿部沿用已保存的 V6 结构**：OB/AC 130mm、BW 105mm、OA/BC 45mm；髋膝法兰、嵌套关节、电机位置和轮组不变。当前保存姿态为髋轮距180mm、Beta=0°。

## 文件

- `wheel_leg_v8.FCStd`：原生 FreeCAD 装配，含运动表达式。
- `wheel_leg_assembly.step`：整机实体交换文件；D435为注明用途的分析包络。
- `wheel_leg_assembly.stl`：整机查看模型，含官方D435可视网格，不用于整机一次打印。
- `cnc/*.step`：承力金属零件；`print/*.stl`：独立PETG件，已按220×220×250mm打印机摆放。
- `CHASSIS.md` / `DISPLAY.md`：分件、装配、屏幕尺寸依据和待核对项目。
- `MASS.md` / `MOTOR_LOAD.md`：本版质量预算、24V V1.1电机负载及屏幕质量敏感性分析。
- `previews/`：实际CAD预览、前脸尺寸图、内部设备布置。

## 主要接口

| 项目 | 本版参数 |
|---|---|
| 机壳主体 | 211×164×155mm，R5，名义壁厚3mm；尺寸不含肩罩和螺钉头 |
| 完整前面板 | 148×144×3mm，R4，可整块拆下 |
| 5寸屏 | 厂家外形122×78×14.5mm；前面X114，中心Y0/Z−4 |
| 屏幕安装 | 托住金属外壳，无需在屏幕上造孔；自制托架4孔为134×60mm，Ø3.4，不是屏幕厂家孔位 |
| D435 | 前面X117，中心Z61，位于屏幕上方；官方可视模型与分析包络用途分别标明 |
| HI13R2 | 保留官方模型与刚性金属桥，厂家名义原点X0/Y0/Z85 |
| Jetson / 电池 | 内置完整Orin Nano开发套件；电池仍按110×50×35mm、400g包络 |

IMU俯视中心沿用左右髋轴中点这一运动学基准。壳体前后范围为X−94～117，包围盒俯视中心为(X11.5,Y0)，与IMU的X0相隔11.5mm；没有为外形变化移动腿部基准或IMU。实际外参需实机标定。

## 制造及验证范围

承重腿件、髋安装框与IMU桥保留金属加工；壳体、肩罩及设备托架为PETG。屏幕规格书没有提供5寸屏的安装孔位、有效显示区、质量或精确插头包络，因此没有沿用旧7寸屏孔距，也没有虚构厂家CAD。屏质量200g仅为工程估计，同时计算100/200/350g情景。

前面板四个0.5mm局部防脱止挡必须落在屏幕金属外框上，不能压玻璃；打印前须核对这一接触面和实物插头尺寸。后侧接线按留空空间检查，不代表任意直头/转接头均可装下。D435不同年份资料有1mm深度差：25.05mm配置用1mm垫片＋M3×6，26.05mm配置去垫片并改M3×5，详见[当前机壳装配说明](CHASSIS.md)。

打印文件已经平移、旋转到落床坐标，装配请使用FCStd/STEP。壳体仍需可拆支撑，不能把封闭网格和打印尺寸检查当作无支撑打印保证。Jetson维护时需拆后横框，并先抬高托盘4mm后再向后抽出，具体顺序见CHASSIS.md。

几何结果只覆盖所列静态装配、离散运动姿态及固定方向维修路径。它们不替代跳跃冲击、疲劳、散热、加工配合或控制稳定性试验。本版未更改MuJoCo模型、腿部姿态或控制器。
