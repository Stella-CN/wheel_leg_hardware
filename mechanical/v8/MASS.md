# V8 质量估算与屏幕质量情景

**屏幕尚未称重。** 5寸GK-HD规格书只给出122×78×14.5mm，未给质量；暂按200g工程估计时，整机约 **6.020kg**。这不是实测定值。

| 屏幕假定质量 g | 整机估算 kg |
|---:|---:|
| 100 | 5.920 |
| 200 | 6.020 |
| 350 | 6.170 |

100～350g仅为屏幕质量敏感性情景，不是厂家公差或整机置信区间；其他零件误差、线材和附件误差仍存在。旧7寸屏265g只用于V7历史对比，不用于本版。

| 200g屏幕情景下类别 | kg |
|---|---:|
| CNC | 1.950 |
| PETG | 0.710 |
| payload | 0.861 |
| motor | 1.920 |
| rubber | 0.144 |
| steel | 0.236 |
| allowance | 0.200 |

设备包括Jetson套件175g、D435 75g、电池400g、HI13R2按11g上界；另留200g未建模安装附件。打印件按完整CAD体积，设备重心按CAD包络均匀体积近似；显示网格不重复计质量。

200g屏幕情景下相对髋中心的整机重心XYZ约-0.12 / -0.03 / -39.70mm；实称后应重算。
