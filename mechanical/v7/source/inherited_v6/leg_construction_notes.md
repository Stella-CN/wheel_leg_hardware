# V6 腿部制造与装配记录

本记录仅说明 CAD 几何和装配关系，不构成跳跃承载合格证明。尺寸单位 mm；S 为膝电机前定子面，当前 S=132.1。

## 五个承重主件

| 零件 | 结构与连接 |
|---|---|
| OB_inner_carrier | 3 厚窄骨架，O 处 D57×4 电机安装盘；中央 D40.4 通道，前部 D50 半环台阶内孔 D44.4，螺孔内侧贯通为断续台阶，避免保留 0.4 薄桥；左侧为 OA 出口。直接固定前定子，B 内支承伸至 S+7.5。 |
| OB_outer_shell | D57 头部，S+20..23 外侧主壁，向内延伸的连续裙边及一体固定凸台形成真实口袋；裙边套过内骨架边缘。下部裙边止于局部 z=-88，给 CW 留出运动出口。 |
| OA_one_piece | OA=45 的一体双叉 CNC 件，穿内座中央孔连接转子；内外叉耳分别 S+4.5..7.5 / S+16.5..19.5。D37 桥止于 S+20.6，前部 D35 鼻颈至 S+23。 |
| AC_bearing_link | AC=130，8 厚，A/C 两端各一个 626 轴承，插入 OA/CW 两叉耳之间。 |
| CW_one_piece | 一体 C 叉、B 中央轴承座和 BW=105 曲线镂空臂；BC=45，B 轴承座插入 OB 两支承之间。W 保留完整承压实体，不把电机内凹腔误当作凸台开大孔。 |

五个主件均采用 6061-T6 铝合金 CNC。全部 A/B/C 轴、轴承保持件、衬套和限位销为独立金属小件。零件曲线和圆角不应被解释为经过拓扑优化或有限元验证。

## 真实嵌套与限位

- 头部外径为 D57，与电机圆面一致；不再使用覆盖整个 OA 扫掠圆的 D101 外盘。OA 长臂由 O 头左侧窗口伸出。
- 内外 OB 的 D50 / D50.2 局部台阶用于装配定位，名义单边间隙 0.10。下臂内架与壳口袋名义横向间隙约 0.25。
- 外壳中央为背侧 D38 阶孔及前侧 D35.4 孔。OA D37 肩到壳阶面名义轴向间隙 0.40；D35 鼻颈到孔单边间隙 0.20。此处是保护/限位配合，不是新增承重轴承。
- 外壳前壁另有 R23、宽 4.6 的圆弧槽，槽中心线对应膝相对角 -135°..-48.5°，D4 销理论首次接触闭端约为 -135.747° / -47.753°。OA 上可拆钢制 M3-D4 肩销经槽安装，D7×1 薄头的底面到外壳前面留 0.7，不夹死运动件。销头具有 0.8 宽、0.5 深一字槽，使用不超过 0.8 的刀片工具。销头局部达到 S+24.7；主结构包络仍为 23。
- 圆弧槽是装配和运动边界。闭端冲击载荷、销根螺纹疲劳及铝槽口局部承压尚未验证，不能用电机冲击该硬止挡。

## 装配顺序

1. 在可操作状态下，将 A 轴承/保持件装入 AC，与 OA 预装；将 C 轴承/保持件装入 AC，并与 CW 预装。装好 A/C 两侧轴端件。
2. OB 内骨架用六个小头螺钉固定到膝前定子。将 OA 转子颈经过其中央圆孔就位；使用六个 M3×16 将 OA 固定到转子。
3. 将 CW 的 B 轴承插入 OB 内骨架，装 B 内支承、垫套和钢轴。外铜套可先压入外壳。
4. 将机构置于名义腿长180，再从正面把整件 OB 外壳沿电机轴向套入；对准 D50 台阶、OA 鼻颈及 B 外支承。用后方四个沉头 M3×10 锁紧两个 OB 的硬接触面。
5. 从外侧 B 的 D9.2 操作孔装外轴端垫片和 M2 低头螺钉。最后经圆弧槽安装 OA 限位肩销。

不得在盖壳前装 B 外侧 D9 轴端垫片和 OA D7 限位销头后再强行压壳；这些头部大于相应通过孔/槽，必须按顺序安装。

检查结果以 [leg_layout_review.json](leg_layout_review.json) 和整机最终验证文件为准。三个局部姿态通过不能证明连续运动区间、全部姿态偏转或跳跃冲击安全。
