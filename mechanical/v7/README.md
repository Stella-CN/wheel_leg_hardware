# V7 屏幕前脸与居中 IMU

基于 V6 改造机身：7 寸屏嵌入前面板，D435 位于屏幕上方，HI13R2 官方模型安装在金属桥架上。造型参考用户提供的 XGO-RIDER 图片，使用独立深色屏框、相机眉部、斜切肩面和收窄侧腹；无独立上舱。腿部结构、杆长、髋膝法兰、电机位置与轮组保持 V6。

## 文件

- `wheel_leg_v7.FCStd`：原生 FreeCAD 整机，保留腿部运动表达式。
- `wheel_leg_assembly.step`：完整实体交换文件；D435 为明确标注的分析包络。
- `wheel_leg_assembly.stl`：整机装配查看；含官方 D435 ROS 可视网格，不用于整机单次打印。
- `cnc/*.step`：金属制造零件；`print/*.stl`：已摆放的独立 PETG 打印件。
- `DISPLAY.md` / `display_interface.json`：屏幕已知参数、假设、可调安装孔。
- `IMU.md` / `imu_interface.json`：官方尺寸、原点、固定方式与轴变换。
- `CHASSIS.md`：分件与装配说明；`MOTOR_LOAD.md`：本版质量和负载复核。

## 新组件

| 组件 | 数据与位置 |
|---|---|
| 7 寸屏 | 用户图165×110×20 mm、约265 g、1024×600，4×Ø3孔；孔中心距150.6377×93.3845 mm。玻璃X119，中心Y0/Z8。 |
| D435 | 官方ROS可视网格，玻璃前面X122，中心Z88；完整安装于前面板，不在机顶。 |
| HI13R2-USB-000 | 官方STEP，26×24×12 mm，预算11 g；厂家图示名义原点(X0,Y0,Z85)，底面Z79。 |
| Jetson / 电池 | 保留完整官方Orin Nano开发套件内部安装；400 g电池仍采用110×50×35 mm包络。 |

IMU 的俯视中心指左右髋轴中点/机身运动学基准，不把不规则外轮廓的面积重心当作传感器基准。厂家图示点存在标注公差，仍需实机外参标定。

## 制造范围

腿部及髋承力框采用6061-T6 CNC；IMU桥刚性连接金属侧框。前后壳、肩罩、屏框与设备托架为PETG，适配220×220×250 mm、0.4 mm喷嘴。屏幕自身孔阵列相对外框偏移及安装耳厚度未提供：已设置±2 mm调节，但最终孔偏移、隔柱长度和屏螺钉长度须按实物核对。图中小数位不代表供应商加工公差。

几何检查不等同于跳跃、疲劳、温升或动力平衡验证。本版未修改MuJoCo模型或控制器，旧仿真不能作为新增设备后实机性能证明。
